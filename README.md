# Flyfespan.R---Easy-Fly-Lifespan-Analysis
Analyze data from fruit fly (Drosophila) longevity assays in R with an easy, customizable script and template. Analyze survival curves for differences in fly lifespan ("flyfespan").

Includes example data and a template for collecting lifespan data during an experiment for future analysis.
================CONTENTS===============

Flyfespan.R - R script for analyzing longevity experiment data (including Kaplan-Meier curve and log rank test)

Lifespan Experiment Directions.pdf - Complete directions and protocol for running a longevity experiment in flies

Lifespan_assay_template.csv - Example template for collecting lifespan data in flies

example_data:
Contains raw example lifespan experiment data from real-life experiments. Contains examples of vial IDs, experimental censoring, positive and negative results, etc. These CSVs can be run through flyfespan.R to obtain analysis examples.

About.txt - details the genotype information in each of the example data files.
